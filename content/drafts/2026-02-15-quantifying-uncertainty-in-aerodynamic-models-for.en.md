This paper addresses the critical need to incorporate model uncertainty when developing aerodynamic models from data, aiming to create probabilistic aerodynamic databases. It explores methods for sampling deterministic functions from two types of probabilistic models: Gaussian Process Regressors (GPRs) and a specific neural network architecture. A key challenge for GPRs is generating consistent function evaluations across multiple samples when input points are not predetermined.

For GPRs, the paper presents an approach to achieve consistent function sampling. For the neural network architecture, which learns a conditional Gaussian distribution by maximizing marginal likelihood, it discusses and compares various options for generating sample functions that align with this learned distribution. The utility of these probabilistic aerodynamic models is then demonstrated through an application in an atmospheric reentry simulation.
